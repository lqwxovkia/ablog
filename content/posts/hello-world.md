## 怎么写文章

- 在 Pages CMS 左侧点「文章」，再点「新建」；
- 填标题、日期、摘要、标签；
- 在正文里正常书写，工具栏可以加粗、加链接、插图等；
- 点保存 → 会自动提交到 GitHub → Cloudflare Pages 自动重新构建 → 大约一分钟后线上就更新了。

## Markdown 基础

你可以用 Markdown 语法，也可以用编辑器工具栏。常用：

- `**加粗**` → **加粗**
- `*斜体*` → *斜体*
- `[链接文字](https://example.com)` → 链接
- 列表、引用、代码块都支持。
